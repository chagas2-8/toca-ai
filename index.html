configuração inicial

Falta configurar o banco de dados

Isso é feito uma vez só, editando o arquivo, antes de publicar. Os convidados nunca vão ver esta tela.

passo a passo

1. Crie um banco gratuito no Firebase (console.firebase.google.com), com o Realtime Database ativado.

2. Copie a "Database URL" (algo como https://seu-projeto-default-rtdb.firebaseio.com).

3. Abra o arquivo index.html, ache a linha const DB_URL = ''; perto do início do script, cole a URL entre as aspas, salve e suba de novo pro GitHub.
